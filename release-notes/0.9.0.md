# Revibe 0.9.0

Revibe is now available as a standalone Windows installer. It bundles its own Java runtime, so neither Java nor a JDK is required.

- YouTube Music playback, search, albums, artists and playlists.
- MusicBrainz/Cover Art Archive and Deezer artwork fallback, high-resolution artwork, disk caching and artwork-derived themes.
- The right-panel artwork now follows the image's real aspect ratio instead of cropping 16:9 stills.
- Local library, playlists, likes, history, lyrics, settings, Supabase sync and Google sign-in.
- Per-user installation with Start Menu and desktop shortcuts, plus a standard uninstaller.

The installer is unsigned. Windows SmartScreen may show a warning until a code-signing certificate is configured.
